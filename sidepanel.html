    Data & privacy

    Matching runs on this device. Enabling profiles downloads Sleeper's public player directory. Sleeper receives the request and IP address, but not your search text.

    Favorites, filters, and appearance are stored locally. Search state and up to six recently viewed player IDs are kept for this browser session, separately for each window. Clear recents at any time from Research.

    Clicking a source sends the selected name or player ID to that website. No account, analytics, or browsing-history access is used.
